# M11.4 pre-registration

**Committed before the sweep exists.** ADR-045 requires the thresholds to precede
the run; this document and `scripts/run_m11_4_preregistration.py` are committed on
their own so the ordering is visible in `git log` rather than asserted in a report.
No sweep code, no held-out evaluation and no contestant comparison exists at this
commit.

Procedure: ADR-041's `omi.inverse.decision_sensitive_threshold`. Experiment design:
ADR-045, as amended (Generator A primary).

---

## What is being tested

Whether constraining an operator to a **declared constitutive form** (Spec §2.2's
proposed sixth category; `docs/V1.4-EDITS.md` E-32) buys extrapolation reach outside
the envelope the training data occupy.

**Generator A** is Kocks–Mecking with a temperature-dependent recovery coefficient
and **one named withheld term** — a strain-rate drag contribution, identically zero
below the reference rate and growing above it. No contestant carries it. Below the
reference rate contestant 2's form is *exactly* the generator's, so its only
in-envelope error is parameter estimation; above it, contestant 2's error is
attributable to one identified missing contribution and nothing else.

**The hold-out is a control-space region, grouped, never random** (CLAUDE.md §5
invariant 6). Training draws strain rates in `[0.01, 5]`, inside `KOCKS_MECKING`'s
declared window `[1e-3, 10]`. Evaluation draws them in `[20, 200]`, outside it — so
the held-out region lies beyond the declared validity range and the extrapolation
report is exercised rather than merely present.

## Contestants

| | Contestant | Declared form? |
|---|---|---|
| 1 | Free-form quadratic surface in `(ρ₀, ln γ̇, T)`, positivity enforced architecturally | no |
| 2 | Correct form, parameters fitted — **calibration arm, not the claim** | yes |
| 3a | Missing *mechanism*: recovery term dropped | yes |
| 3b | Missing *dependence*: recovery coefficient treated as constant | yes |
| 4 | Tabular baselines from `omi.baseline`, unchanged | no |

Contestant 1's feature set deliberately includes `ln γ̇` — the functional form the
withheld term actually takes — so the free-form arm is given the chance to learn the
missing physics from in-envelope data. It cannot, because the term is identically
zero there. That is the experiment, not a handicap imposed on the baseline.

## Declared inputs to the threshold

| Input | Value | Basis |
|---|---|---|
| `minimum_effect` | **0.701923** | 10% of the withheld term's mean absolute contribution over the held-out region (7.019) |
| `cost_false_alarm` | 3.0 | see below |
| `cost_miss` | 1.0 | |
| `standard_error` | per comparison, below | seed-to-seed sd of the gap estimator, measured **in-envelope only** |

**The cost ratio is set against the party that wants the positive finding.** A false
alarm — claiming declared physics buys reach when it does not — is three times as
costly as a miss, because the false alarm is the direction that would put an
unsupported claim into a paper and this experiment exists to support a claim. The
ratio raises `τ`, making a positive result harder to obtain.

**Why `minimum_effect` is scaled off the withheld physics, not off any error.** The
size of the withheld drag term over the held-out region is a property of the
*generator*, which the experimenter authored. It is computed by running the
generator twice, with and without that term, and differencing — no contestant is
fitted, no prediction is made, no error is measured. Consulting it therefore does
not amount to seeing the result the threshold will judge, and it is the only
quantity available in advance carrying the right scale for an extrapolation effect.

## Pre-registered thresholds

Per comparison against contestant 1, since a single global threshold would be driven
by whichever arm happens to be noisiest and would impose that arm's noise on every
other test:

| Comparison | gap sd (in-envelope) | **τ** |
|---|---|---|
| 1 − 2 (correct form) | 0.02042 | **0.35161** |
| 1 − 3a (missing mechanism) | 0.15679 | **0.38944** |
| 1 − 3b (missing dependence) | 0.10143 | **0.36706** |
| 1 − 4 Ridge | 0.02100 | **0.35165** |
| 1 − 4 GBT | 0.04014 | **0.35348** |

**Decision rule, fixed now.** A gap in held-out RMSE counts as a real effect only if
it exceeds that comparison's `τ`. The same values apply to Generator B if it runs.
Per ADR-045, Generator B is **not** run if Generator A shows no benefit.

## Two things recorded because the pilot caught them

**A first threshold attempt produced `τ = 5.02`**, larger than most of the errors
being compared. That was not a formula failure — ADR-041's own docstring predicts
it ("shrinking `minimum_effect` toward `standard_error` makes τ increasingly
sensitive... the two classes are no longer easily separable by the estimator's own
precision"). It was a **scale error**: `minimum_effect` was taken as 10% of
contestant 1's *in-envelope* RMSE (0.054), where every contestant does well, giving
a declared effect 29× smaller than the estimator's own noise. Catching this before
the sweep is precisely what the pre-registration step is for, and it is recorded
rather than silently corrected.

**A second fault in the same attempt**: the standard error was taken as the *worst*
gap sd across all contestants (0.157), which is driven by contestant 3a, whose own
in-envelope RMSE is ≈ 2.4. Imposing the noisiest arm's variability on every
comparison is over-conservative without being principled. ADR-041's formula is
per-criterion, so the thresholds are now per-comparison.

## The limitation of this pre-registration, stated in advance

The standard errors are measured **in-envelope**, because measuring them on the
held-out region would mean looking at the numbers the threshold exists to judge.
In-envelope variability may *understate* held-out variability, since extrapolation
amplifies parameter uncertainty. An understated standard error makes τ **tighter**
and a positive finding **easier** — so this choice is anti-conservative in the
direction of the claim, not self-serving in the usual sense but still a limitation.
Any positive result must be read with it in mind, and the sweep report repeats it.

## Reproduction

```
python scripts/run_m11_4_preregistration.py
```

Seeded throughout (`default_rng(1000+i)` for training draws, `default_rng(5000+i)`
for evaluation draws, `default_rng(99)` for the withheld-term magnitude), so the
values above are reproducible at this commit.
