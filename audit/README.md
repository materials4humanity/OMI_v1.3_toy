# audit/

`pre-m11-observations.json` — the observation record from a full test-suite run at
commit **`57f7db8`** ("M10.4 Part B: plan the proposed-v1.4 constitutive track"),
the last commit before `src/omi/` was touched by the proposed-v1.4 extension. **267
observations.**

It is the baseline for the audit-preservation gate (ADR-042, `docs/DECISIONS.md`;
M11.1, `docs/ROADMAP.md`): the claim that every quantity the repository measured
before M11 is byte-identical after M11, and that the extension only *added*
observations. Run the check from a clean clone with:

```bash
scripts/check_audit_gate.sh audit/pre-m11-observations.json
```

Unlike `build/observations.json` (git-ignored, regenerated by every test run), this
file is committed and never regenerated in place — it is a fixed reference. It was
verified authentic by regenerating it from a fresh checkout of `57f7db8`
(byte-identical). See `REPRODUCE.md` §7 for the regeneration recipe.
